## 新手速览

**车削** 是让**工件旋转**、**刀具静止进给**的工艺，专门做"回转体"——轴、盘、套、螺纹、内外圆。和铣削正好相反：铣削是刀转、工件基本不动；车削是工件转、刀走。

![车削原理示意](/assets/diagrams/turning.svg)

## 基本原理

- **主运动**：工件绕主轴高速旋转（转速 S）；
- **进给运动**：车刀沿轴向（Z）或径向（X）平移，切除材料；
- 适合加工**回转对称**特征的零件，材料去除效率高、表面质量好。

## 主要加工内容

| 内容 | 说明 |
|---|---|
| 外圆 / 端面 | 最基础的车削 |
| 内孔（钻/镗/铰） | 加工轴套内表面 |
| 切槽 / 切断 | 成形槽与分离 |
| 螺纹 | 通过主轴-进给严格联动实现 |

## 设备演进

1. **普通车床**：手动/机械进给，依赖技工经验；
2. **数控车床（CNC Lathe）**：程序控制，重复精度高；
3. **车铣复合（Turn-Mill / Multitasking）**：在一台机床上完成车、铣、钻、攻丝，减少装夹；
4. **瑞士型车床（Swiss-type / 走心机）**：工件由导套支撑、沿轴向送进，适合**极细长轴类**（如医疗骨钉、钟表件），刚性好、精度高。

<div class="note tip">车铣复合的价值在于"一次装夹完成多工序"——装夹次数越少，累积误差越小，特别适合复杂小件的大批量精密加工。</div>

## 与铣削的取舍

- 回转体特征 → 优先车削（效率高）；
- 非回转/多面特征 → 需要铣削或车铣复合；
- 薄壁回转件 → 注意装夹变形与振刀。
