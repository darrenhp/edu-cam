## 新手速览

"这个零件该用什么工艺做？"没有公式，但有一条**决策框架**：先看**形状特征**，再看**材料**，最后看**精度与批量**。下面给出通用思路，供建立直觉。

## 决策框架

### 第一步：看几何特征

| 特征 | 优先工艺 |
|---|---|
| 回转体（轴/盘/套） | [车削](/processes/turning.html) |
| 平面/型腔/非回转外形 | [铣削](/processes/milling.html) |
| 复杂曲面 / 深腔 | [五轴](/processes/5-axis.html) 或 3+2 |
| 硬材深槽 / 异形轮廓 | [电火花 EDM](/processes/edm.html) |
| 高硬淬火面 | 磨削 / [高速铣](/processes/milling.html) |

### 第二步：看材料

- 易切（铝/低碳钢）→ 常规铣/车即可；
- 难切（钛/高温合金）→ 降参数、强冷却，或走 EDM/磨削；
- 非金属/复材 → 关注分层与专用刀具（见[材料可加工性](/processes/materials.html)）。

### 第三步：看精度与批量

- 高精小批 → 五轴/单件精修，重装夹次数控制；
- 大批量 → 车铣复合、自动化产线、一致性优先；
- 强监管行业（医疗/汽车）→ 体系认证与[检测闭环](/processes/metrology.html)。

## 典型场景速查

- **手机金属中框**：CNC 铣 + 高表面质量，外观面精修；
- **航空整体叶盘**：五轴联动 + 专用策略；
- **注塑模具型腔**：铣 + EDM 清角 + 抛光；
- **医疗骨钉（细长轴）**：[瑞士型车床](/processes/turning.html)；
- **新能源电机壳（大铝件）**：大扭矩铣 + 高效去料。
