## 新手速览

**刀具路径（Toolpath）** 就是"刀尖依次经过的空间点序列"。CAM 的核心工作，就是自动算出这一长串点，让刀既能把多余材料去掉，又不撞到工件、不过切、表面还漂亮。

机床能同时联动几个轴，决定了刀路有多"自由"：

| 类型 | 同时联动轴数 | 一句话理解 |
|---|---|---|
| 2.5 轴 | X/Y + Z 分步 | 平面轮廓 + 分层铣，Z 不与其他轴联动 |
| 3 轴 | X/Y/Z | 刀轴始终垂直向下，最常见 |
| 4 轴 | X/Y/Z + 旋转 A/B | 工件可绕一轴转，加工圆柱类零件 |
| 5 轴 | X/Y/Z + 两个旋转 | 刀轴可任意摆，加工复杂曲面 |

## 刀具路径是怎么算出来的

无论几轴，刀路生成大致是同一套路：

1. **偏置（Offset）**：沿零件曲面法向偏出一个"刀具半径"，得到刀具中心应走的曲面；
2. **走刀方式**：平行铣、等高铣（Z 向分层）、螺旋铣、适应性铣等；
3. **步距与残余高度**：控制相邻刀路间距，决定表面粗糙度；
4. **进退刀与连接**：避免直接扎刀，用圆弧/斜线平滑切入；
5. **碰撞与干涉检查**：刀柄、夹持会不会碰到工件或夹具。

<div class="note info">现代 CAM 普遍具备"自适应清角""残料加工"等策略：只削该削的地方，显著缩短工时并延长刀具寿命。</div>

## 2.5 轴加工

- **特征**：X、Y 做轮廓插补，Z 轴只在层间做"快速移动 + 下刀"，不与其他轴同时插补。
- **典型应用**：平面轮廓、型腔、刻字、钻孔（点位控制）。
- **优势**：编程简单、机床便宜、可靠性高，是绝大多数机加工车间的主力。

## 3 轴加工

- **特征**：X/Y/Z 三轴联动，但**刀轴方向固定（通常垂直）**。
- **典型应用**：模具型腔、平板类零件、大部分普通结构件。
- **局限**：遇到深腔侧壁、倒扣、陡峭斜面时，要么需多次装夹，要么残留"刀痕"。

## 4 轴加工（3+1 与 3+2 与 全4轴）

- **3+1 / 3+2（定轴加工）**：第四轴仅用于**分度定位**（转到一个角度后锁死），再走 3 轴刀路。性价比高，常用于凸轮、叶轮端面。
- **全 4 轴联动**：第四轴参与插补，适合加工旋转对称的连续曲面（如螺杆、圆柱凸轮）。

## 5 轴加工

- **特征**：在 3 轴基础上增加两个旋转轴（常见为转台 + 摆头，A/C 或 B/C 组合），刀轴可在空间中**任意取向**。
- **两大模式**：
  - **5 轴定位（3+2）**：先摆好一个固定刀轴角度，再做 3 轴加工——能用更短刀具加工深腔，刚性更好。
  - **5 轴联动**：五个轴同时插补，加工自由曲面（如整体叶盘、复杂模具）。
- **价值**：
  - 用**短而粗的刀具**加工深腔 → 刚性高、振刀少、表面好；
  - **一次装夹**完成多面 → 累积误差小；
  - 刀轴始终**垂直于加工面（点接触→面接触）** → 表面质量与效率双升。

<div class="note warn">5 轴对后处理器、机床标定、仿真的要求远高于 3 轴。后处理一旦出错，极易发生"旋转轴翻转导致撞机"，因此仿真校验不可或缺（见[仿真与碰撞检测](/cam/simulation.html)）。</div>

## 运动自由度示意（简化）

```text
3 轴：  刀轴 ↓ 固定
        ┌─────────┐
        │  工件    │  ← 只能从上往下削
        └─────────┘

5 轴：  刀轴 ↗ 可摆
         \      ┌─────────┐
          \→    │  工件    │  ← 可贴着斜面削
                └─────────┘
```
