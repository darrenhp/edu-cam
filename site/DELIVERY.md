## 如何运行

```bash
cd site
npm install          # 已安装
npm run build        # 生成 dist/
npm run serve        # 本地预览 http://localhost:4173
```

构建器：`site/scripts/build.mjs`（Markdown + gray-matter front-matter → 共享布局 → 静态 HTML）。
设计系统：`site/src/css/main.css`（CSS 变量 token：钢蓝主色 + 中性灰）。
内容源：`site/content/<板块>/<slug>.md`，正文为 Markdown，front-matter 含 title/order/tags/sources/updated。
